# Interaction toolkit access and licensing

## Public visualization package

This public snapshot distributes interaction analysis and visualization code. The interaction-extraction and sparsification implementations are not included because of copyright and licensing restrictions.

Reproducing figures from the archived interaction arrays does not require SITKit or an extraction-toolkit activation. Download the inputs from Zenodo and follow the root README. The data archive's own terms still apply.

## Public demonstration

An illustrative interaction-extraction workflow is available from the official [SymTrustAI/SITKit project](https://github.com/SymtrustAI/SITKit). See [our demo entry](demo/README.md) for the upstream quickstart, notebook, and release links. No SITKit source, wheel, or example dataset is redistributed here.
